# HMS comparison

Generated by `./benchmarks/competitive/hms-bench table` from the committed files in `benchmarks/results/competitive/`; do not edit by hand. Every cell is indexed with its source file and key path in [comparison.cells.json](comparison.cells.json). Method, caveats and how to reproduce: [README.md](README.md).

Rows are never compared across hardware classes: each section is one dataset on one hardware class. A verdict is WIN or LOSS only when the 95% bootstrap interval of the advantage factor excludes 1 (deterministic byte counts use a 5% band); otherwise TIE. The advantage factor is always oriented so that more than 1 means HMS is better. Hosted-runner rows carry noise; trust the ratios, not the absolute values.
