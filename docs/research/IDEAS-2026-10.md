# Ideas tree, October 2026: a step, not a percent

Session artefact of the 2026-10-07 Fable session. Goal: move HMS by a step in the three arenas
(ANN single-thread QPS and index bytes at recall@10 0.90 / 0.95; BEIR nDCG@10; LongMemEval S-dev
end-to-end accuracy) and in product correctness. Ideas come from four methods (axiom relaxation,
isomorphic mapping, counterfactual targets, adversarial counterfactual), are pruned by 10-minute
proxies on dev or held-out data, and only survivors are measured properly.

Rules applied throughout: every number here traces to a file in `benchmarks/results/`; proxies
never read `test.f32`, `neighbors.i32`, BEIR test qrels or the held-out LongMemEval ids; a proxy
that cannot change a decision is not run; no Modal or API spend.

Proxy code: `benchmarks/public/proxies/` (`qgraph_sim.py` is a numpy model of the VGraph search
over a graph read from the HMSGRF02 cache; it reproduces the Rust evaluation counts exactly and
recall within about one point, so it is used for counts and recalls, never for time). Proxy
results: `benchmarks/results/proxies_2026-10.json` (ANN), `proxies_2026-10_lme.json`,
`proxies_2026-10_beir.json`.

## 3. Isomorphic mappings

### 3.1 Graph search as branch-and-bound with the code estimate as a heuristic (ANN)

Objects: vertices = nodes; the ef-pool = the open list; the k-th best fine score = the incumbent;
the 8-bit estimate = the heuristic h(v). Operations: expansion = pop the best open node, push its
children. Invariant: branch-and-bound is exact only when h is admissible (never overestimates the
distance) and it prunes a node when h(v) exceeds the incumbent. Our estimate is not admissible: it
has symmetric error, so pruning on it loses recall, which is why the pool holds ef candidates
rather than pruning on a bound. What the mapping imports: (a) an admissible bound exists cheaply:
|<q, x> - <q, x~>| <= ||q|| ||x - x~|| and ||x - x~|| is known per vertex at build (the residual
norm), so est - scale_err is a true lower bound on the distance; (b) with an admissible bound the
stop rule becomes exact: stop when the best open bound is worse than the k-th incumbent, and no
fixed ef is needed. What is lost: the bound is loose for 8-bit codes (residual norms are small but
not zero), so the exact rule stops later than the heuristic one; whether it stops earlier than a
fixed ef is exactly the `oracle_stop` question. Proxy: `oracle_stop` (the oracle ratio bounds the
gain; the "k-th best unchanged for t steps" rule is the cheapest non-learned stop). Not an
analogy: the structure is identical.

### 3.2 Quantization as rate-distortion and lattice codes (ANN)

Objects: a vertex code = a point of a codebook; bits per vertex = the rate; the estimate error
= the distortion. The current code is a cubic lattice (Z^d scaled per vertex) with one scale.
Theory: at equal rate, (a) a rotation that whitens the coordinates (Gaussianizes them) lowers the
distortion of a scalar quantizer on heavy-tailed data; (b) an asymmetric (min/max) scalar
quantizer uses all 256 levels; (c) entropy-coded or lattice (E8, Leech) codes gain up to 1.53 dB
over cubic at the same rate but cost decode time, which the kernel cannot afford at 20 ns per
estimate; (d) RaBitQ's 1-bit code with a rotation is the rate-1 point of the same curve and its
theory gives the error bound used in (3.1). Imports: rotation (cheap at query time: one d x d
product per query) and LVQ-style min/max. Proxy: `quantizers`. Not an analogy.

### 3.3 Graph build as nearest-neighbour descent (ANN)

Vamana's insert pass searches each vertex from the entry (build_ef) then prunes; NN-descent
instead iterates "a neighbour of a neighbour is likely a neighbour" and converges in a few sweeps
with no search. Imports: (a) NN-descent as the candidate generator for the prune, which removes
the build search that is 85% of glove's build time (spec A3); (b) the alpha-prune is identical
in both, so the graph quality question reduces to the candidate set. Proxy for quality:
`build_params` (alpha and build_ef sweep on 100k rows). Build time is the one metric where losing
is accepted, so this mapping is recorded, not expanded, unless the recall result moves.

### 3.4 Supersession as a bitemporal database with MVCC (agent memory)

Objects: a fact = a row version with valid-time (the event date stated in the text) and
transaction-time (the session date); a question = a query "as of" the question date, or over a
valid-time range. MVCC semantics: the newest version visible at the as-of time wins; older
versions are retained for "what did I say before" questions. The current pipeline stores only
transaction time (M2) and returns every version (M6); the reader resolves. Imports: extract
valid time at ingest (an LLM `dates` stage, specified in spec C lever ii) and index both; answer
temporal questions by valid time and knowledge-update questions by transaction time. Proxy:
`event_dates` (how often valid time differs from transaction time in the evidence). Analogy only
in part: the retrieval is a ranking, not a point lookup, so the MVCC visibility rule becomes a
boost, not a filter.

### 3.5 Memory as a cache hierarchy with admission policies (agent memory)

Objects: the store = a cache; sessions = lines; the question = an access. The hit rate is
recall_all@K; K = the associativity. Admission policy = what gets a key (facts, turns, expanded
turns); replacement = none (the store grows). Imports: (a) the "one line per set" principle:
multi-session questions need one hit per session, so the ranking should admit at most m turns per
session before taking a second turn from any session (set-associative diversification); (b)
prefetching = session-level retrieval followed by turn-level retrieval inside the hit sessions.
Proxy: `diversify` on cached dev embeddings. Analogy (the memory is read, not evicted), but the
diversification rule is concrete.

### 3.6 VSA cleanup as sparse recovery (holographic memory)

Objects: a superposed trace = y = A s where A is the codebook (D x N, +-1 entries) and s the
0/1 membership vector; cleanup = recover s from y. Theory: compressed sensing recovers K-sparse s
with D ~ K log N measurements when A is random; the capacity curves in `holographic_dev.json`
(sign codes fail past K ~ 128 at D = 16,384, random codes past K ~ 512) are exactly the
difference between a structured and a random sensing matrix. Imports: (a) iterative hard
thresholding or OMP as the cleanup (resonator networks are the VSA name for it), which raises the
recoverable K by a constant factor; (b) the result also says why sign codes of embeddings
underperform random codes: they are correlated columns. Proxy: none needed, the capacity file
already shows the K cliff; the dev accuracy of the holographic arms (0.117 to 0.213) is far
below the index (0.821 recall), so this mapping is recorded and not expanded this session.

### 3.7 Hybrid fusion as rank aggregation / social choice (text retrieval)

RRF is Borda-like with a 1/(k0 + rank) kernel. The theory (Kemeny, Condorcet fusion) says rank
fusion ignores score margins, which is what the measured +0.017 of a min-max blend on LongMemEval
sessions showed (`longmemeval_dev_ablation.json`). Import: a calibrated score blend with a
per-query normalization. Proxy: `fusion` on BEIR dev / train qrels. Analogy, but the proxy is
direct.

### 3.8 Learned traversal as a stopping problem (optimal stopping, secretary problem)

Each expansion reveals one more candidate; the reward is recall, the cost is evaluations. The
secretary-problem structure (stop after the best-so-far has not improved for a fraction of the
horizon) is exactly the "k-th best unchanged for t expansions" rule. Analogy, but it names the
cheapest non-learned policy; proxy `oracle_stop`.

## 4. Counterfactual targets

### ANN: 2x QPS at recall 0.95 at equal or fewer bytes

QPS = 1 / (evals x ns_per_eval). Twice the QPS means either half the evaluations at the same
recall (14,850 -> 7,400 on nytimes held-out) or half the nanoseconds per evaluation (20.7 -> 10.4
ns, which is below one cache-line fetch per estimate and therefore requires fewer bytes per
estimate, i.e. the 4-bit code, which already gave x1.2 on nytimes and x1.0 on glove), or a
product of the two. Mechanisms and the proxy that bounds each:

- Early termination (A2, A3): the oracle ratio is the ceiling of what any policy can save.
- Better entry (A1): bounded by the oracle-entry proxy.
- Better estimator (A5 to A7): fewer re-rank candidates and a smaller ef for the same recall.
- Cheaper screen (A8): if most evaluated neighbours never enter the pool, a 4-bit first pass with
  8-bit confirmation halves the bytes per discarded neighbour.
- Better graph (A12): fewer hops at the same recall.
- Error classes that must vanish for 0.95 at ef 128 instead of 384: the true neighbours that the
  pool never sees (`true_neighbours_ever_seen` in `oracle_stop`) versus the ones seen but ranked
  out (`rerank_ceiling`).

### Text retrieval: BEIR nDCG@10 average up by a step (0.68 -> 0.72 on SciFact)

The published numbers that define a step are encoder numbers (SPLADE v3, Qwen3-Embedding-8B);
no index change moves nDCG@10 by 0.04 when exact cosine equals the NumPy reference. What must be
true: the encoder changes (T3), or the hybrid gains a calibrated blend (T1) and proper BM25 (T2),
each worth about 0.01 to 0.02. The honest counterfactual is that a step in this arena is a model
decision (spec B, $150) and this session can only bank the index-side 0.02.

### Agent memory: end-to-end accuracy up by a step

There is no baseline number, so the first step is the reader run itself (spec C). What this
session can move is the retrieval input to it: multi-session recall_all@5 from 0.625 toward the
0.93 of the other types (M1), and dating (M2). Twice the gap closed on multi-session (24 of 84 dev
questions) moves the overall turn recall_all@5 by about 0.04.

### Adversarial counterfactual: a competitor publishes 2x next month

Most likely technique on ann-benchmarks-style CPU numbers: SymphonyQG-style 1-bit edge codes with
FastScan (already in the retired edge index), plus RaBitQ 4-bit extended codes with an
error-bound-based early stop, on AVX-512 with batched queries. On single-thread, one-query, the
realistic 2x comes from (a) the bytes per estimate (4-bit or 1-bit screen) and (b) AVX-512 FastScan
over 32 codes per instruction. We can adopt (a) now (opt-in 4-bit is x1.2 on nytimes); (b) is the
x86 port (spec X) and is not measurable on this M4. What we can surpass: the error-bound stop
(3.1) is cheap to add and SymphonyQG does not use it.

## 8. Holographic Neural Manifolds: curvature mechanism test

The user authorized a software research prototype with operational curvature. The initial
implementation is `src/core/manifold.rs`, behind `experimental`, and the reproducible harness is
`src/bin/manifold-memory-bench.rs`. It does not change document retrieval or published defaults.

The base geometry is the Poincare disk with sectional curvature `-c`, `c` in `[0, 1]`. The
`c = 0` control uses the continuous flat limit, twice ambient Euclidean distance. For points
`x, y` strictly inside the unit disk:

$$
d_c(x,y)=\frac{2}{\sqrt c}\operatorname{asinh}
  \frac{\sqrt c\lVert x-y\rVert}
  {\sqrt{(1-c\lVert x\rVert^2)(1-c\lVert y\rVert^2)}}.
$$

Transport is the rotation part of Levi-Civita parallel transport between **orthonormal conformal
frames**, quantized to the existing phase substrate's `Z_N`. Coordinate tangent vectors would
also need a conformal scale ratio. The implementation is checked against the independent
gyrovector expression `gyr[y, -x]`, not just against inverse transport. Foundations:
[Poincare embeddings](https://arxiv.org/abs/1705.08039),
[Geoopt parallel transport and gyration](https://geoopt.readthedocs.io/en/latest/_modules/geoopt/manifolds/stereographic/math.html),
and [gauge-equivariant geometric message passing](https://arxiv.org/abs/2003.05425).
These are prior art; originality of the memory construction has not been established.

Each record's bound key/value trace is distributed over anchor locations by a normalized
geodesic radial footprint `phi(x)`, with the phase at each anchor transported from `x`:

$$
M_{i,d}=\sum_f\phi_i(x_f)(k_f\odot v_f)_d,\qquad
y_d=\overline{k_d}\sum_i\overline{\phi_i(x)}X_{i,d},\qquad
(I+\tau L_U)X=M.
$$

The Hermitian positive-semidefinite connection Laplacian uses a fixed ambient three-neighbor
graph. Fixed Jacobi iterations produce an immutable readout snapshot, with the relative
linear-system residual retained. The raw field remains available for additive updates; a
snapshot borrows the source, preventing updates while that readout is in use. Record identity,
deduplication and lifecycle enforcement remain caller responsibilities; this is not a durable
store. Gauge tests require equivalent recall after changing local frames, including relaxation.
Nontrivial loop transport distinguishes connection curvature from a coordinate relabeling.

## 9. Physics-inspired direction: reconstructible boundary memory

The useful physics analogy is **bulk/boundary error correction**. The
[HaPPY construction](https://arxiv.org/abs/1503.06237) encodes logical bulk degrees of freedom
in a redundant boundary tensor network; particular logical operators can be reconstructed
from multiple boundary regions. This suggests a classical software research question:
can a query reconstruct its requested logical memory from a small surviving portion of a
distributed code, while preserving ordered relations and charging all redundancy?
It does not imply unlimited compression or quantum behavior on an ordinary CPU.

### Translate mechanisms, retain their resource limits

| Inspiration | Software mechanism worth considering | Constraint |
|---|---|---|
| Entanglement and teleportation | Prearranged correlated encodings, followed by versioned delta transfer | Synchronization requires communication; shared coordinates cannot convey an unseen update. |
| No-cloning and destructive state transfer | Explicit ownership transfer for mutable working state | Classical data remain copyable; deleting a source does not prevent copying or eavesdropping, and a query should not consume durable evidence. |
| Surface codes and boundary reconstruction | Classical parity checks, local erasure repair, and query-specific decoding | Recovery needs retained redundancy; code distance, repair reads, and decoder memory have costs. |
| Curved manifolds and Poincare disks | Intrinsic hierarchy geometry and path-dependent transport | Bounded coordinates have finite precision; fewer dimensions can require more bits per coordinate. |
| Minkowski space and folded time | Separate event time, observation time, and directed causal paths | Temporal proximity is not causality; folding coordinates does not remove retrieval or indexing work. |
| Metabolic decay and neuroplasticity | Consolidation with an explicit importance and retention policy | Rare evidence may be valuable; exact regrowth requires a retained cold source or reconstructible code. |
| Optical vortices and resonance | Distinct phase channels and streaming matched filters | A CPU still performs encoding and arithmetic; overlapping channels have finite capacity and false matches. |
| Event horizons | Recoverable summaries of a restricted logical state | An arbitrary damaged interior cannot be recovered from an insufficient boundary description. |

The [original teleportation protocol](https://research.ibm.com/publications/teleporting-an-unknown-quantum-state-via-dual-classical-and-einstein-podolsky-rosen-channels)
requires a shared entangled pair **and a classical message** before the receiver can
reconstruct the state. Entanglement does not provide instantaneous replication. The
[hyperbolic representation tradeoff](https://arxiv.org/abs/1804.03329) explicitly includes
precision as well as dimension; infinite mathematical extent is not infinite digital capacity.
These are physical and information limits, not shortcomings that a different index can evade.

### Candidate construction and the originality boundary

Use **Holographic Neural Manifolds** as the research program name. The hypothesis has three
coupled parts, none implemented by section 8's kernel:

1. **Encode relations as ordered paths.** Apply role-dependent operators to record states,
   so order and context affect the fiber representation itself, not only its location.
   A path uses the ordered product `T_gamma = T_e_m ... T_e_1`. Noncommuting operators
   can distinguish reversed relational chains; scalar phase multiplication alone cannot.
   Permutation-plus-phase operators are a practical starting control. Gauge-equivalent
   frames must produce equivalent answers. Existing VSA role permutations and ordered
   binding are prior art, not a new contribution by themselves.
2. **Encode logical content on a finite boundary.** Store coded shards associated with
   boundary patches of a curved multiscale layout. Learn or select the layout against
   a declared query family, rather than assuming arbitrary data are harmonic or that
   a geometric boundary automatically determines their interior. Exact exceptions and
   provenance witnesses remain retained and counted. Full boundary redundancy must fit
   inside the same byte budget as the controls.
3. **Decode the requested observable.** Find a surviving boundary subset sufficient for
   a query, reconstruct its ordered relation or value, and verify it against retained
   evidence. If the available code cannot identify the answer, report absence or
   uncertainty. Geometric transport may guide subset selection; it cannot invent lost
   information. Known curvature-induced holonomy is expected structure, not an error
   syndrome. Corruption checks must be defined against the actual encoder's constraints.

A finite-field linear surrogate makes the boundary claim falsifiable. Let `z` contain `m`
logical symbols, let `E` be an `n x m` encoder, and store `b = E z`. A query requests
`w_q^T z`. For surviving rows `S`, exact recovery exists precisely when a vector `r` satisfies:

$$r^T E_S = w_q^T,\qquad \operatorname{answer}(q)=r^T b_S.$$

This is a row-space condition. Recovering every possible `z` requires rank `m` and at least
`m` independent surviving symbols; erasure tolerance requires additional redundancy.
A particular query may need fewer symbols. Computing the subset and `r` also has a cost;
precomputed decoders are charged to storage. Classical parity checks satisfy `H E = 0`,
with syndrome `H b`; a nonzero syndrome detects some corruptions, not all of them.
Byte-exact parity arithmetic uses a declared finite field, not floating-point phase rotations.
This surrogate is an algebraic specification, not a claim that the current field has such a code.
It is not a new coding principle: [functional batch codes](https://arxiv.org/abs/2101.06722)
already recover requested linear combinations from disjoint server subsets, and
[locally repairable codes](https://arxiv.org/abs/1206.3804) characterize the tradeoff between
repair locality, distance, and storage. These are required controls, not competitors to
rename as a holographic invention.

The original-research candidate is the **joint optimization of relation encoding, curved
layout, and query-specific recoverability under online updates and a fixed resource budget**.
It must outperform separating those components. Simply adding error correction to holographic
memory is already established: a
[2016 Walsh-Hadamard memory construction](https://www.sciencedirect.com/science/article/pii/S0893608016000253)
uses redundant transforms, and a
[2026 holographic associative-memory study](https://link.springer.com/article/10.1007/s44427-026-00031-w)
uses Reed-Muller responses. The HaPPY model is quantum prior art, not an implemented classical
semantic store. This targeted literature check does not establish priority for the joint design.

### Next experiment and rejection criteria

First address section 8's demonstrated within-context bottleneck: ordered relations and
trajectory-dependent cues must change the encoded record state. Compare with strong
permutation/role-bound VSA controls and an exact attributed graph on identical facts, including
reversed edges, coincident entities, and multiple attributes at one context. Test independent
metric and transport ablations; a curve in a diagram is insufficient evidence.

Only after a representation gain should the boundary mechanism be evaluated. Compare it with
the same representation plus conventional erasure coding, locally repairable codes, and
functional batch codes, then ablate learned boundary placement and selective decoding.
Use identical information, equal total bytes,
calibration-only selection, paired held-out seeds, measured p95 latency, repair bytes read,
update amplification, and source-witness accounting. Include random and contiguous shard
erasures, stale versions, correlated cue noise, and contradictory temporal records. Do not
silently answer a historical query with a repaired but newer version.

The existing product target remains twice the recoverable facts at 95% exact recall,
equal total memory, and no worse p95 latency. A separate resilience claim must beat
conventional coded storage on query or repair cost at matched recall and bytes; a resilience
win is not automatically a capacity win. Abandon the joint hypothesis if the gain disappears
when role-aware encoding, code redundancy, witnesses, and decoder costs are included.
This is a proposed research direction, with no measured advantage yet.

## 10. Ordered phase paths: protocol before the held-out run

The next authorized experiment implements `src/core/phase_path.rs` and
`src/bin/phase-path-bench.rs`, both behind `experimental`. It changes the key state,
addressing section 8's spatial-factorization bottleneck without changing production retrieval.

The primitive is a monomial unitary operator on quantized phases:
`(A z)[d] = exp(i theta[d]) z[p[d]]`. Its permutation and phase offsets compose as
an ordered matrix product and admit an exact inverse in the quantized substrate. Dense
complex-matrix oracles check the composition, action, and adjoint; multi-edge tests check
that intermediate frame changes cancel. Noncommutative matrix binding is established prior
art: [MBAT](https://arxiv.org/abs/2202.04771) and
[Generalized Holographic Reduced Representations](https://arxiv.org/abs/2405.09689).
The research question here concerns geometry-conditioned path encoding at a fixed resource
budget; neither a noncommuting permutation nor an inverse is a novelty claim.

Protocol fixed before inspecting held-out output:

- Synthetic complete stored paths: 16 subjects, 8 relation types, 4 attributes, 64 value IDs.
  Every forward/reversed path pair shares a subject and attribute but has different values.
  Labels are random. This tests ordered associative recall, not inferring an unseen path's
  answer from constituent edges.
- Two layouts: all vertices coincident, and walks on a deterministic relation-labelled graph
  with vertices inside the disk. Each query receives the complete ordered relation IDs,
  attribute ID, corrupted subject phase vector, and noisy path coordinates. All arms receive
  the same information and corruption. There are no language models or paid services.
- Seven arms: commutative binding as an order-collision sanity control; positional role binding
  with flat or curved geometric features as strong controls; monomial path binding with
  metric and connection curvature varied independently in four arms. Geometric edge offsets
  combine quantized geodesic-distance frequencies with integer-weighted transport phases.
  These designed diagonal features are not a learned connection or a claim that arbitrary
  role operators themselves are Levi-Civita transport.
- Every arm tries the same nine distance/spin settings: distance `0, 0.5, 2`, spin `0, 1, 4`.
  Zero weights allow geometry to be rejected. Three calibration seeds select each setting;
  first settings win ties. The stronger positional baseline is also selected on calibration
  only. No held-out retuning. All calibration runs are retained.
- The model payload cap is 65,536 bytes. Each arm uses its largest fitting dimension in
  `32..=4096`, including codebook headers and phase buffers, complex128 accumulator, geometric
  coefficients, permutation/phase operator banks, lookup table, and model metadata. No
  padding is used: simpler controls receive additional dimensions. Unused bytes from integer
  dimension rounding are reported through each actual model payload. Actual source-witness
  struct and Vec buffers are added to every model; fixture/query storage, allocator overhead,
  and process RSS are excluded. This is a matched model cap plus equally charged witnesses,
  not a claim of identical allocated bytes or compressed storage of arbitrary records.
  Total payload grows with the witness count as fact load grows; this sweep cannot establish
  doubled capacity across loads at equal total bytes.
- Sweep: 16/64/256/1024 facts, path depths 2/4, coordinate noise `0/0.04`, and 5% independent
  subject-phase replacement: 32 conditions. Thirty held-out seeds start at `20271008`,
  disjoint from calibration beginning `20261008`. Up to 128 queries per seed. Paired seed
  bootstrap intervals use 2,000 resamples; intervals are exploratory without multiplicity
  correction. Fixture fingerprints, dimensions, bytes, reverse-value mistakes, and per-seed
  counts are retained.
- An exact attributed path-table scan filters on ordered relations and attribute, then compares
  subject phase cues. It uses the selected positional control's subject dimension, receives
  the same information, and reports its witness/codebook bytes and timings separately.
- Indicative local p95 includes encoding the path, unbinding, and exhaustive value-codebook
  decoding. Held-out arm order rotates by seed. Build and input-corruption costs are separate;
  these timings do not establish a load-gated competitor speed advantage.

The combined mechanism passes only if both-curved improves over the calibration-selected
positional control with a positive paired interval, and independently removing metric or
connection curvature also hurts with positive paired intervals. A win over the commutative
sanity arm alone proves only that ordering matters. The product target still requires twice
the facts at 95% exact recall, equal total memory, and no worse p95 latency. Boundary coding
is deferred until an encoding gain survives these controls.

## 11. Next experiments after the two geometry negatives

These are ranked proposals, not new measurements. Sections 8 and 10 tested designed
geometry on synthetic facts; neither found a qualifying advantage. A better next test
should remove a measured cost or exploit an explicit source of predictable structure.
This ranking is an inference about research value, not a numerical success probability.

### 11.1 Implicit algebraic value codes and transform decoding

**First practical experiment.** In section 10's representative 300-dimensional positional
control, the 64 value vectors alone contain 38,400 phase-buffer bytes out of 65,400 model
bytes, before counting their vector metadata. Cleanup also scans all 64 vectors. Replace
this stored random value bank with implicitly generated Walsh characters. For an alphabet
of 64 labels and a dimension divisible by 64, use

```text
v_label[d] = (-1)^popcount(label & (d mod 64))
```

After unbinding the cue, sum the real readout over matching coordinate classes and apply
a 64-point fast Walsh-Hadamard transform. This computes the 64 correlation scores in
`O(D + L log L)` operations rather than the current `O(D L)` scan. It does not remove
cross-talk or make retrieval independent of dimension. Larger or open-ended alphabets
need another coding construction or explicit typed namespaces whose mappings must be
charged; the 64-label result would not establish arbitrary text retrieval performance.

Controls: current stored random codes, bit-packed four-bit random codes, seeded regenerated
random codes with their generation/scan cost, and implicit algebraic codes. First compare
at equal dimension to expose any noise penalty; then fit each arm to equal total bytes,
including all remaining books, witnesses, namespaces, lookup tables and peak decoding
workspace. Retain exact attributed lookup as a product control. Test noisy cues, erasures,
addition/subtraction drift and increasing label counts, using calibration-only choices.

For the existing 16-subject/8-role/4-attribute/64-value fixture, a hypothetical fully packed
four-bit random bank plus complex128 accumulator costs `92/2 + 16 = 62` bytes per
dimension before fixed overhead. Removing the value bank leaves `28/2 + 16 = 30`, or
about 2.07 times the dimension headroom. This is allocation arithmetic, not measured
capacity, and excludes coefficients, metadata, witness costs and alignment constraints.

The basic method is established coding theory, and Reed-Muller response codes have
already been used with holographic associative memory:
[Román, 2026](https://link.springer.com/article/10.1007/s44427-026-00031-w) and
[Abbe, Shpilka and Ye](https://arxiv.org/abs/2002.03317). A possible later research
contribution would jointly learn local semantic charts and their coding alphabets;
it would have to beat ordinary flat typed namespaces with the same information.

### 11.2 Learned manifold schemas with lossless innovation storage

**Strongest original-research candidate.** Train a compact model of repeated relational
structure, and store exact corrections where its reconstruction disagrees with the
observed facts. A chart represents a reusable schema; transitions between charts represent
relation transformations. Select geometry by the total description length of model,
membership and corrections, subject to query latency and faithful reconstruction.
The hypothesis is that a learned curved atlas plus a holographic correction channel can
reduce both exception volume and decoding ambiguity on structured streams.

Example: reconstruct repeated configuration defaults from a shared schema while retaining
each override and its provenance. All admitted facts need membership information;
unobserved predictions are inferred answers and must not be returned as witnessed facts.
Corrections must have a lossless representation or a fully charged exact sidecar. Model
versions and corrections must remain compatible across consolidation; retaining old
versions or rebuilding corrections has a measurable storage/update cost.

For a known predictor with independent 10% errors uniformly distributed over the other
63 labels, ideal conditional coding needs `h2(0.1) + 0.1 log2(63) = 1.067` bits per value
instead of six bits for an independent uniform 64-label value. This illustrative calculation
excludes predictor, membership, provenance and random-access index costs. It explains the
opportunity; it does not establish a whole-system compression ratio.

Test structured and random-label controls at 1%, 10%, 50% and 100% schema violations,
held-out entities and later timestamps, with schema drift, deletion and supersession.
Compare flat learned schemas plus exact corrections, low-rank models plus sparse
corrections, dependency-based compression, and compact indexed records with ordinary
compression. Curvature must contribute beyond the shared-schema baseline at equal
parameter/byte budgets. Separate observed-fact reconstruction from unseen-path reasoning.

Dependency-based compression is prior art, including
[Squish](https://arxiv.org/abs/1602.04256); a predictor plus exceptions is not itself novel.
The proposed contribution is the joint online chart/connection/correction mechanism and
its demonstrated advantage, if any. No novelty or superiority claim is established yet.

### 11.3 Spatially coupled encoding with full decoder accounting

**Best existing positive lead, requiring a stricter follow-up.**
`docs/SUPERPOSITION-FLOOR.md` reports recall of 0.43 for an uncoupled code and 0.92 for
a coupled code at `M/D = 0.29`. That comparison charges the stored trace. Its prototype
`scripts/superposition_floor_coded.py` also allocates a dense float64 sensing matrix of
shape `(D, M * L)`, including zeros in the coupled construction, and uses up to 300 AMP
iterations. The reported trace advantage is not a demonstrated total-memory or latency win.

Try implicit or structured sensing operators with bounded decoding windows, paying for
their representations, seeds, caches, residual state and workspace. Compare uncoupled
AMP with the same implementation improvements, compact indexed records, and conventional
coded storage. Test random queries as well as whole-bundle recovery, streaming insertions,
removals, noise and erasures. Windowing and structured matrices may lose the observed gain;
they are hypotheses rather than consequences of the published capacity theorem.

[Spatially coupled SPARC theory](https://arxiv.org/abs/2002.07844) provides a strong known
baseline. A potential HMS contribution would be an online, query-local construction with
a measured gain after full accounting, rather than rediscovering spatial coupling.

### 11.4 Constraint-assisted reconstruction across semantic charts

**Higher-risk mathematical experiment.** Combine ambiguous holographic readouts with
independently validated type, inverse-relation, composition and temporal constraints.
Use local chart agreements to restrict candidate reconstructions or detect incompatible
ones. Cellular sheaves offer a mathematical language for such local-to-global consistency;
their use in learned graph geometry is already established by
[Neural Sheaf Diffusion](https://arxiv.org/abs/2202.04579).

Test whether jointly encoding constraints and facts corrects more errors per total byte
than adding ordinary parity or retaining an explicit constraint graph. Give a generic
factor-graph/belief-propagation control exactly the same constraints and evidence.
Include corruptions, missing observations, contradictory rules, stale versions and
unseen compositions. Never provide held-out answers as constraints or treat every loop
as having zero holonomy; genuine relation order and curvature can produce valid loop
effects. If several reconstructions satisfy the available constraints, abstain rather
than claim exact recovery. Sheaf diffusion is not an error-correction guarantee.

### Shared decision rule

Run 11.1 as the smallest cost-removal test and prioritize 11.2 for original research.
Retain 11.3 only if its trace-only advantage survives full accounting; use 11.4 when the
dataset supplies validated redundant relations. Select all tuning on disjoint calibration
data. Report held-out paired intervals, exact-answer accuracy, provenance correctness,
total resident/serialized bytes, peak workspace, p95 query time and update costs.

For a substantial HMS storage win, the existing target remains twice the facts at at least
95% exact recall, equal total memory and no worse p95 latency against the strongest
eligible baseline. Compare exact attributed storage wherever it supports the same query.
A subsystem improvement, a compression result and an unseen-query reasoning result are
different claims and need separate evidence. Section 12 executes proposal 11.1; section 13 tests a bounded version of 11.2.
Proposals 11.3 and 11.4 remain untested here.

## 13. Learned manifold schemas with lossless exceptions

### Contribution candidate and prior-art boundary

Section 11.2 is tested as a bounded, batch-consolidated categorical atlas. Learned chart
centers, local label phases, metric curvature and parallel transport jointly determine the
prediction. A membership-gated, lossless correction channel reconstructs admitted values;
model replacement rebuilds corrections before replacing the snapshot. The candidate
contribution is a reduction in **total queryable memory under schema changes**, attributable
to metric and transport after charging version migration. It is not the predictor-plus-
exceptions pattern: [SQUISH](https://arxiv.org/abs/1602.04256) already exploits relational
dependencies, and [latent-variable tabular compression](https://proceedings.mlr.press/v202/montanari23a.html)
charges learned latent representations alongside lossless residual coding. Learned hyperbolic
representations and Riemannian optimization are established by
[Poincare embeddings](https://arxiv.org/abs/1705.08039) and the
[Lorentz-model follow-up](https://proceedings.mlr.press/v80/nickel18a.html).
This targeted primary-source review establishes relevant controls, not priority. This
prototype learns a finite atlas over supplied coordinates; it does not learn an entity
embedding from raw language and does not implement holographic residual superposition.

### Protocol fixed before measurement (2026-10-08)

- Eight arms: learned flat charts; learned curved metric and transport; metric only;
  transport only; categorical dependency tables; additive low-rank categorical schemas;
  packed indexed records; block-LZ4 packed indexed records. All receive the same quantized
  two-dimensional entity coordinates, category, and four attribute identities. Values are
  16 categorical labels. Coordinate/category sidecars and provenance cost every arm bytes.
- The atlas uses eight trainable medoid centers and four local categorical phases per
  chart. Deterministic alternating label fitting and center proposals use training entities
  only. Disjoint calibration entities choose curvature from 0.25/0.5/1.0 and connection
  on/off; the flat arm has identical center and label budgets. Selection minimizes model
  payload plus actual correction payload on calibration, with deterministic ties. No
  held-out tuning or post-result parameter changes.
- Six streams: hierarchy, flat spatial structure, held-out angular sector, later temporal
  drift, deletion, and supersession. For each, override rates 1%, 10%, 50%, 100% replace
  structured labels by an independent uniform label (100% is the random-label control).
  Deletion removes every fifth admitted slot; supersession changes every fifth slot and
  increments its revision. Queries cover all slots, out-of-domain entities, absent slots,
  and wrong model versions. Unadmitted predictions remain explicitly inferred.
- Loads: 32/64/128/256/512/1024/2048/4096/8192 slots (four per entity), 30 paired held-out seeds from
  20301008, disjoint training/calibration seeds derived by explicit domain separation.
  A two-seed pilot from 903101 exercises the harness without changing the protocol.
- Membership is a bitset. Corrections are a bitset plus packed four-bit exact replacements,
  with prefix ranks for bounded random access; raw packed values are the compact control.
  Every arm uses the same block-LZ4 columnar provenance codec with raw fallback.
  Provenance includes source ID, event tick and revision; these are lossless witnesses,
  not signatures or retained source documents. Membership, witness payload, coordinates,
  chart/model versions, capacities, random-access indexes, query workspace and consolidation
  workspace are reported as capacity-based conservative bounds, excluding allocator overhead.
  Both logical binary-layout payload (not a persistence format) and resident model-plus-query
  memory are charged. Allocator overhead, process RSS, executable code, benchmark fixtures, timing
  samples and report buffers are excluded and must not be called total application memory.
- Every admitted value and witness is checked, including after replacement by a new model
  version. Query timing uses warmed, preallocated workspace, 256 deterministic queries,
  individual latency samples and rotating arm order. p95 is local and instrumented.
  Consolidation time and simultaneous old/new snapshot plus rebuild workspace are reported;
  workspace uses conservative bounds and excludes allocator overhead.
- Primary: under a 65,536-byte peak-accounted cap (maximum of query, training and consolidation), twice the contiguous qualifying
  admitted-fact capacity of **each** eligible baseline, exact recall interval lower bound
  at least 95%, and paired p95 ratio upper bound at most 1 at the respective qualifying
  loads. Also report equal-load bytes and paired exception fractions. Require both metric
  and transport to reduce held-out correction counts versus their ablations, with positive
  paired 95% intervals, before attributing a gain to the joint geometry. Thirty seed means,
  2,000 paired bootstrap draws, exploratory intervals without multiplicity correction.
  Capacity at the last grid point is censored; neither extrapolate nor infer a doubling
  beyond the tested range. A standalone Python checker independently regenerates fixtures,
  computes geometric predictions and accounting, and recomputes intervals and decisions.

The cap was set to 65,536 bytes before any pilot or measurements so the dependency learner's
32,768-byte count table fits. Consolidation includes simultaneous old/new snapshots and
reconstruction buffers; training workspace is charged separately and included in the cap.

Protocol recorded before implementation measurements; validated results follow below. A negative result rejects this
bounded construction; it is not an impossibility theorem about learned geometry.

Implementation clarifications recorded before the pilot completes: source witnesses are
compressed in 64-observation columnar blocks for **every** arm; the LZ4-record arm additionally
compresses packed values in 128-byte blocks, with raw fallback. The locked LZ4 0.14 encoder's
8,192-byte small-input hash table is charged in construction/consolidation workspace.
The additive categorical baseline is a rank-one complex phase factorization (category phase
plus attribute phase modulo 16), not real-valued matrix completion. Dependency tables predict
attributes from category and the exactly retained first attribute; a missing parent uses an
explicit zero input and exceptions preserve observed children. The hierarchy generator uses
an independent closed-form curved atlas and is deliberately favorable to the hypothesis;
flat and random controls are essential. Models learn medoids and local phases, not coordinates
for each entity. All test entity identities belong to a separate namespace from training and
calibration. The held-out-sector stream additionally withholds a category/angular sector.

These snapshots preserve **current** observations only. Supersession increments source
revision and rebuilds corrections; deletion removes current membership. Historical versions
are not retained or answerable, and stale model-version queries fail. Consolidation is pure:
a replacement is fully built before a caller could swap it, so a rejected change leaves the
original intact. This is recoverable batch replacement, not a durable online database,
concurrent update protocol, signed provenance system, or a completed holographic atlas.

Pilot validation: 3,456 rows at two seeds (`903101`) passed independent fixture, training,
prediction, provenance, correction and accounting checks. The pilot selected no settings.
Before the held-out run, lint-only fixes and an accounting correction charge the two
512-byte shifted-label buffers used in drift training. Interpretation also explicitly
requires fewer corrections than the flat arm, in addition to both ablations, to count
a joint-geometry mechanism success; no predictor or latency setting changed.


### Result and decision

**Negative primary result: none of the 24 stream/override groups meets the 2x capacity
and latency target.** The held-out sweep completed 216 conditions, eight arms and 30 seeds
(51,840 rows) in 189.00 seconds. All 91,043,520 current admitted observation reads matched

## 14. Direction-preserving conversation geometry: protocol before measurement

The maintainer asks for overall superiority and a more aggressive attack on assumptions.
That objective remains unachieved. The next risk is a representation change on real
memory data, rather than another synthetic curvature variant. Section 13 reduced some
label corrections without removing membership, evidence or workspace; a new mechanism
must eliminate a measured whole-system cost. Competitor speed comparisons still need a
quiet, matched-recall run and x86 verification. No experiment below substitutes for that.

Assumption under test: independently storing a full vector for every turn is necessary
to find a conversation's relevant evidence. Learn a small basis of each conversation's
turn embeddings and search its geometry. A linear subspace has a specific flaw: projection
energy is identical for a query and its negative. An additional **signed support** arm
retains compact per-turn coordinates and scores their maximum signed dot product; this
preserves direction and evidence identities. This is a higher-risk alternative to
independent vectors, not a claim that nobody has considered subspaces.

Low-rank language geometry is established by
[Mu, Bhat and Viswanath (2017)](https://aclanthology.org/P17-2099/) and subspace set retrieval by
[Ishibashi et al. (2024)](https://aclanthology.org/2024.naacl-long.192/).
Scalar compression is a strong ordinary control, including
[LVQ](https://arxiv.org/abs/2304.04759).
The possible contribution is direction-preserving, evidence-addressable conversation
geometry with a measured full-cost advantage, not PCA, SVD or support functions themselves.
A targeted primary-source review is not a novelty audit.

Protocol fixed on 2026-10-08 before the new representation is scored:

  export; 84 questions pass the existing official scoring filter. The 400 held-out question

  no new LLM calls, query rewrite tuning, reader or judge. Corpus embeddings alone fit
  the session basis; questions, gold labels and answers never select basis parameters.
- Ranks 1/2/4/8, float16 and row-scaled int8; ordinary and singular-value-weighted
  projection energy. Signed support uses the same quantized basis, its Gram inverse,
  and float16 per-turn coordinates. Gram correction pays for the quantized basis's
  non-orthogonality. Mean pooling and deterministic farthest-first representative turns
  receive the same vector budgets. Full float16, int8 and packed four-bit turn scans

  support also supports a standalone approximate turn ranking without that sidecar.
- Retain every observed user turn, original turn/session identity and conversation date

  the pinned cleaned release. Charge source evidence, membership/ID directories, model

## 15. Evidence completeness: quality protocol before measurement

The maintainer now prioritizes a leap in quality. This preserves the overall superiority
objective while moving the next hypothesis from storage to a measured failure mode:
the tuned pipeline's multi-session turn recall_all@5 is 0.625, versus 0.821 overall.
This is retrieval coverage, not end-to-end answer accuracy. The previous diversification
proxy already tested session quotas and round-robin retrieval; those are not new leads.

Assumption: independently merging each query variant's ranked list also produces the
best **set** of evidence. A question that compares several events needs every operand.
Summing scores rewards one well-covered operand even when another is missing. The
candidate objective maximizes the weakest facet's coverage within a five-turn evidence
budget, together with relevance to the full question. A bounded beam searches through
intermediate sets whose missing operand would give a greedy method no immediate gain.
The original top turn remains an anchor; questions without at least two distinct cached
subqueries retain the original ranking.

Set retrieval is established prior art:
[Yadav et al. (2021)](https://aclanthology.org/2021.naacl-main.363/),
[non-negative elastic-net decoding](https://arxiv.org/abs/2606.17910), and
[CABLE's complementary memory links](https://arxiv.org/abs/2608.17911).
This experiment is an inexpensive falsifier for evidence completeness, not a new
algorithm claim. A later original contribution would need independently witnessed
relational/temporal obligations and an advantage over these stronger systems.

Fixed before the new set selectors are scored:

- Frozen S dev only. Reconstruct the **tuned** pipeline from its cached document scores,
  query variants and reranker, and require agreement with the recorded cached-run baseline.
  The weak raw-dense arm is not the deciding baseline. No new model calls or spending.
- Obtain facets from the existing cached subqueries; infer no gold operands. Each facet
  is independently retrieved with the existing turn key/fusion settings and no original-
  query reranker. Candidates are the original top 64 turns plus the first ten of each
  facet; all IDs must belong to the observed source archive. Facet compatibility is
  `1/sqrt(1+facet_rank)`; whole-query relevance is `1/sqrt(1+baseline_rank)`.
- At five turns, maximize `alpha * sum(relevance)/5 + (1-alpha) * coverage`.
  Proposed coverage is the minimum across facets of their best selected compatibility;
  the ordinary coverage control averages those maxima. Beam width 32, anchor fixed,

  mean-coverage beam. Alphas 0.25/0.50/0.75 only; all tried results are reported.

  type using seed 20261008. Select alpha separately for each family on calibration

  calibration; confirmation never selects a method or setting. This is a new internal
  confirmation split of previously used dev data, not untouched public held-out data.
- A quality-leap proxy requires confirmation turn recall_all@5 to rise >=0.05 overall
  and >=0.10 on multi-session, a positive paired 95% bootstrap lower bound overall,

## 18. Route to broader superiority (2026-10-09, research decision)

Scope: pursue agent-memory quality, vector-index efficiency, and a distinctive
holographic contribution. This section is a proposed programme, not a measured
improvement, an execution log, or a replacement for the frozen operand protocol.
No held-out question, new model run, paid service, commit or publication is used
to develop this decision. The dominance language in `NEXT-SESSIONS.md` is an
aspiration; sections 14–17 and `PUBLIC-BENCHMARKS.md` describe the actual evidence.

### 18.1 What can produce the next substantial gain

The strongest supported direction is **complete, source-backed memory with
explicit reasoning obligations**, served by an efficient index. The successful
operand experiment identifies which original statements a question needs;
it does not establish that VSA storage or a reader can answer correctly.
Keep source truth and candidate-generation representation separate, and test
their contributions separately. An implementation can combine a conventional
source store, VGraph candidate retrieval, operand selection and optional VSA
relation lookup without attributing their combined result to the algebra.

The dev selector already attains its anchored same-byte top-20 oracle: 79/84.
The five unresolved evidence cases divide into three missing candidates and
two over-budget support sets. Another selector sweep on these same candidates
cannot exceed that measured bound under the same anchoring and packet rules.
This is a bound for this dev experiment, not an answer-accuracy ceiling or a
general limit. Candidate expansion can address the first class; an explicitly
different resource contract is needed for the second. Token budgets and byte
budgets must both be measured rather than treated as interchangeable.

| Arena | Next causal test | What would justify investment |
| --- | --- | --- |
| Agent memory | Same reader sees first-five, strong knapsack and operand packets | Better answer correctness and source-supported citations at matched context cost |
| ANN | Reach 0.95 recall, then compare matched native query loops | A reproducible throughput/bytes advantage against the strongest feasible competitor configurations |
| Holographic representation | Bound relation lookup with exact source verification versus ordinary relation indexes | A benefit that disappears when binding is removed and survives complete resource accounting |

### 18.2 Agent memory: complete the answer path before more selection tuning

First implement the missing dev reader/judge surface in spec C of
`NEXT-SESSIONS.md`; the current `longmemeval_modal.py` runs retrieval and has no
reader stage. Reuse its model revisions, cache and budget accounting. Its listed
reader command is a future interface, not a currently executable command.
Before execution, amend and freeze the answer protocol: the old prompt's rule
that the newest session is current is unsafe for retrospective statements,
future plans and conflicting sources. Distinguish conversation observation
time, explicit event time and inferred validity; retain unknown dates and
unresolved conflicts. Apply the same corrected prompt to every arm.

Use all 100 dev questions for answer evaluation, including abstention and
assistant-dependent questions omitted from the 84-question user-turn coverage
metric. Give every arm the same role policy; test full-role ingestion as a
separate change rather than dropping hard questions. The upstream
[LongMemEval reader guidance](https://github.com/xiaowu0162/LongMemEval#memory-reading)
explicitly supports assistant messages and an extraction-then-reasoning reader.
Keep answer labels and answer-marked source IDs outside selector and reader
inputs; the judge alone receives reference answers. Opaque IDs must preserve
distinct source occurrences and actual dates.

Run first-five, anchored knapsack and frozen operand arms first. Share question
text, reader/judge, decoding, chronological presentation and evidence wrapper.
Count the complete serialized reader input with the reader tokenizer, including
dates, source IDs and instructions; enforce a common evidence-token cap selected
before results. Keep the existing byte-capped experiment as its own arm and
report any effect of the additional token cap. Never truncate a source and
continue counting it as complete evidence. Record selection failures explicitly.

Require atomic answer claims with source citations, plus explicit abstention.
Validate citation membership and quotation fidelity mechanically; these checks
do not establish entailment. Use blinded, shuffled arm identities for judging
answer correctness and claim support. Retain the official correctness score
alongside a separate citation-support score, and report disagreements and
judge failures without excluding them from the denominator. Audit disagreements
against raw source; no answer labels may feed back into the test system.
Repeated judge calls on a fixed preselected sample estimate grading instability.

Only after this baseline should a single new candidate-generation mechanism be
tested: expand candidates using missing entity/relation/date obligations, then
rerank and select whole sources. Absence of a lexical witness is not proof that
an answer is absent; expansion should retain semantic retrieval as a fallback.
Measure candidate coverage, packet completeness, conditional reader success,
unsupported answers and false abstentions separately. This locates the loss
instead of assigning every error to retrieval.

Event/validity metadata, relation closure, verified arithmetic and conflict
handling are candidate improvements, not existing features. Numbers need units,
distinct event identities and explicit operands before arithmetic; plans must
not become completed events. Session dates do not automatically establish
event dates or supersession. Store every derived assertion with its source
references and unresolved status. Keep the frozen packet's `i` empty until a
separately evaluated inference interface exists.

### 18.3 ANN: fix the measurement and the 0.95 gap first

Use the existing held-out **train-vector** tuning protocol, independently of the
400 held-out memory questions. Diagnose candidate-pool coverage versus final
quantized reranking before changing quantizers: exact reranking over the same
pool distinguishes traversal failures from distance-estimation failures.
Raw reranking is a diagnostic control; if retained for serving, its vectors
count against index bytes. Choose ef, refinement depth and stopping parameters
on tuning vectors only; do not iterate against the already viewed test sweep.

Retest the existing patience and four-bit paths before adding another heuristic.
The earlier one-bit screen already lost end-to-end despite its kernel win;
section A0 of `NEXT-SESSIONS.md` identifies serialized survivor fetches as the
reason. The next mechanism worth testing is pipelined neighbor screening and
refinement that overlaps memory fetches. It must improve the complete query
loop, including bookkeeping and query transformation, at unchanged recall.
[SymphonyQG's official implementation](https://vectordb-ntu.github.io/RaBitQ-Library/index/qg/)
uses batched distance estimation and supports raw, four-bit and eight-bit
refinement; compare these configurations rather than an obsolete weak baseline.

Run HMS, FAISS, hnswlib, SymphonyQG and RaBitQ in one native timing protocol on
the same idle machine, with pinned versions, threads, affinity where available,
warmup, alternating order and equal query-interface overhead. Keep one-query
latency separate from batching throughput. Use the existing 11 paired rounds
and load gate; an unmet gate produces preliminary timing, not a speed claim.
Measure 0.90 and 0.95 recall on both nytimes and glove, with a bracket at each
target, and then an unseen third distribution. Report full serving bytes,
resident peak, workspace, build time and raw-vector/refinement sidecars.
Publish x86 claims only after x86 measurements; M4 results cannot stand in.

A speed win over FAISS cannot erase a size loss to RaBitQ or a speed loss to
SymphonyQG. Plot recall/throughput/bytes frontiers and identify precisely where
HMS dominates. Extend scale only after a survivor passes the small-data gate;
find the capacity cliff rather than extrapolating one successful size.

### 18.4 Holographic representation: test computation, not a storage miracle

Stop reviving rejected curvature, manifold, projection-energy and codebook
storage schemes without a new falsifiable mechanism. Their retained controls
already account for exceptions, directories, exact refinement and source text.
Superposition has finite capacity because of crosstalk, as analysed by
[Frady, Kleyko and Sommer](https://arxiv.org/abs/1707.01429).
The inference for HMS is that unrestricted lossless source storage in a compact
trace is a poor next bet; this is an engineering judgment, not an impossibility
proof for every representation.

The bounded candidate is **compositional entity/role/time relation lookup**:
bind already extracted source-backed slots, unbind a requested relation to
produce candidates, and verify each returned candidate against the exact source
store. Reuse the existing compositional prototype specified in C2; do not start
another geometry subsystem. Ambiguous extraction remains ambiguous, and an
unbinding score is neither a factual answer nor evidence of absence.

Use identical extracted slots, source documents, query workload and update
semantics for VSA, a hash/posting relation index, a conventional graph and a
quantized flat scan. Also include the tuned retrieval path. Removing role/time
binding must isolate the claimed compositional effect. Charge extraction,
codebooks, cleanup vocabulary, source pointers, source payloads, redundancy,
scratch space, updates and rebuilds. Vary relations, occupancy, dimensions,
collisions and replacement/deletion rates to find the cliff. Test genuinely
unseen combinations with independently generated fixture seeds; synthetic
success still requires a later real-data confirmation.

Proposed promotion gate: at least 2x lower total memory or 2x faster verified
relation queries than the best conventional control, with equivalent supported
answer quality and update correctness. Freeze exact quality tolerances and
confidence calculations before measuring. If VSA helps only under corruption,
compare equal-byte replication and erasure coding and report the clean-data
cost; the earlier shard experiment already found substantial costs there.
A conventional control tying the result defeats a distinctive VSA claim.

### 18.5 Proof ladder and execution order

1. Build the matched dev answer baseline and independent citation validator.
   Freeze role policy, prompts, token accounting and failure treatment first.
2. Diagnose the 0.95 ANN failure and complete a matched timing harness. Select
   one survivor on train-vector tuning data; measure on reserved evaluation data.
3. Run the bounded compositional ablation with conventional controls. Port it
   into production only after its resource/quality gate passes.
4. Integrate only survivors; measure retrieval through validated answer,
   including cold load, warm p50/p95, ingest, reranking, selection, reader,
   verification, resident memory and total cost. Separate common reader cost
   from memory-system cost, but report both.
5. Freeze the full system, comparator versions and analysis before a single
   authorized held-out confirmation. S and M share question identities; do not
   treat the same 400 IDs on the other variant as a fresh confirmation set.
   Current scripts reserve those IDs for the final M run; preserve that rule.

Proposed agent-memory gate: a positive paired answer-accuracy difference against
every measured comparator with a simultaneous 95% lower confidence bound above
zero, plus citation fidelity, p95 latency and resource use meeting preregistered
noninferiority margins. Fix primary comparisons, multiplicity correction,
minimum meaningful effect and margins before the confirmation. Publish per-type
intervals and raw paired outcomes; a tiny category cannot establish parity from
a nonsignificant difference. If 400 questions cannot resolve a small lead,
report uncertainty and use a new independent dataset instead of retuning them.
An internal win on 100 reused dev questions is a promotion signal only.

The comparator surface matters. As checked on 2026-10-09,
[Mem0's benchmark repository](https://github.com/mem0ai/memory-benchmarks)
distinguishes its managed v3 platform result (474/500 at top-50) from OSS.
[Zep's research page](https://www.getzep.com/research/) reports 451/500 using
`gpt-5.4` for reader and judge and multiple retrieval scopes. Running Mem0 OSS
or Graphiti locally is useful, but does not reproduce either managed product.
Pin the actual comparator variant and apply the same reader/judge/context cap;
retain vendor-native results separately to show the effect of normalization.
Published percentages alone cannot supply the matched comparison.

Operational locality is a useful product property, not evidence that vectors
conceal source information. Security claims remain bounded by `SECURITY.md` and
`PRIVACY.md`; no PoSME, RATS verification or encrypted-data search claim follows.
No new spend or held-out execution is implied by this proposed programme.

The practical route is to win each measured frontier, then demonstrate that the
combined system retains those wins. General superiority remains unproven until
the matched evaluations establish it; representation novelty is an additional
claim requiring its own successful ablation.
