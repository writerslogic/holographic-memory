A memory in one vector

4,096 bits hold every key-value pair at once. Pick how many pairs, damage the memory, and ask for one value back.

Similarity of the unbound memory to each known value

    What is being computed

    Each key and each value is a random 4,096-bit vector. A pair is key XOR value. The memory is the bitwise majority of all pairs, then damage flips the chosen share of its bits. To ask, XOR the memory with a key and measure the fraction of matching bits against every value. Unrelated vectors match about half their bits, with a spread near 0.8 percentage points, so a match well above 0.5 is the stored value. More pairs shrink the signal; more damage shrinks it too. Past some point the answer is wrong, and the demo says so.
