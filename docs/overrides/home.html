Why holographic

A hologram stores the whole picture in every fragment. A hypervector memory does the same: many facts are superposed into one long vector, no single bit holds any one fact, and damage is spread thinly over all of them.

  1. Bind a key to a value with XOR. The result looks like neither, and binding again with the key gives the value back.
  2. Bundle many bound pairs by majority vote into one vector that stays a little similar to each of them.
  3. Resonate: unbind with a key and compare against known values. The right one stands out from the noise, even after you corrupt the memory.

The demo uses dense binary vectors so the algebra is easy to see. The engine uses sparse binary vectors, and its document search does not rank with hypervectors; the concepts page says exactly which parts do.
